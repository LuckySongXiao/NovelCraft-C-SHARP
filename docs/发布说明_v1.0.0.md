## 1. 产品简介

书籍管理系统是一款基于 **C# / .NET 8.0 WPF** 的智能书籍创作与管理平台，以本地 RWKV 大语言模型推理为核心 AI 引擎，覆盖长篇小说创作的完整闭环：

- **项目管理**：多书籍并行管理、回收站、导入导出整包交付
- **内容创作**：卷宗章节结构化编辑、AI 润色/续写/对话生成
- **设定体系**：世界观、修炼体系、政治/商业/功法/装备等 20+ 维度设定
- **AI 流水线**：对话式五级创作流水线（总纲→剧情线→分卷→章节草稿→章节正文）、一键成书、长篇批量生成
- **质量保障**：一致性检查、项目体检报告、统计聚合
- **运维支撑**：SQLite 本地存储、一键备份/恢复、健康检查、诊断包导出

## 4. 本版核心更新（相对首个内部版本）

### 4.1 AI 创作助手（对话式创作流水线）
- 标题栏机器人按钮开合 380px 对话抽屉
- **意图导航**：输入「打开剧情管理」等指令直接跳页；自然语言由规则优先 + RWKV 兜底解析，目标白名单校验，绝不误导航
- **五级流水线**：总纲 → 剧情线 → 分卷 → 章节草稿 → 章节正文；每级产出以确认卡呈现，支持单项采纳/修改/放弃、整卡全部采纳或放弃重生成
- **章节关联处理**：输入框左侧链接按钮关联已有 书→卷→章，此后对话直接对目标章节改写/成文/答疑，发送「取消关联」解除
- **状态持久化**：流水线进度落库，重启应用后自动恢复继续创作

### 4.2 章节续写/润色全面修复
- 润色弹窗**模型下拉框动态加载**：自动扫描 `rwkv_models` 目录真实模型文件，服务当前加载的模型标记「当前在线」并默认选中
- **两级在线探测**：弹窗打开时执行「状态端点 3 秒 + 1-token 推理 6 秒」探测，服务离线或隧道假死立即给出中文指引，不再长时间等待后报裸英文错误
- **选中段精准润色**：编辑器内选中文本后润色，仅替换选中段落；未选中则润色全文，应用前可确认范围
- 续写设置面板布局修复，完整显示全部参数；连接类异常统一转中文提示

### 4.3 角色唯一性保障（本版新增修复）
- **服务层幂等防重**：同项目内创建「同名 + 性格 + 背景」完全一致的角色时自动复用现有角色，杜绝 AI 生成与批量回填产生的不可区分重复角色
- **重名但描述不同允许创建**，符合角色设定多样性
- 手工创建/AI 生成命中防重时给出明确提示，UI 列表不再出现重复行
- 存量重复数据已全量清理（软删除，可恢复）

### 4.4 修为等级 AI 自定义体系
- 「修炼体系」页可由 RWKV 生成全书自定义等级体系（如灵根共鸣者→…→维度织者八级）
- 体系落库后，角色编辑对话框的修为下拉框动态加载本项目自定义等级，支持按等级自动回填
- 体系参与一致性检查

### 4.5 长篇批量生成与一键成书
- **一键生成书籍**：RWKV 双 Agent 自动构思书名 → 生成大纲 → 写出第一章并创建新项目
- **长篇批量生成**：无限续写模式、快速切卷、每卷章节数（3–100）与每章目标字数（800–10000）自定义
- **切片续写 + DRY 抗复读**：换提示词重试 + 滚动会话携带尾部上下文，显著降低复读
- **断点续跑**：任务按章节切片落库，中断后自动从断点继续；8K~1M 上下文分档写作策略

### 4.6 界面与体验
- 白夜/黑夜主题全覆盖（含输入控件、下拉框、弹窗外框深浅反色修复）
- 自定义皮肤配置 + 女频书籍自动换肤（pink 皮肤）
- 侧栏导航展开状态持久化，重启后精确恢复
- 章节命名 Agent 自动生成主题章节名；关系图自适应缩放；仪表盘最近活动真实动态

### 4.7 数据保障
- 项目体检报告（健康检查）、一键数据库备份/恢复、诊断包导出（自动脱敏）
- 导出功能修复空引用崩溃；TXT/DOCX 内容导出、项目整包导入导出

## 5. 已知问题与限制

| 编号 | 描述 | 规避方式 |
|---|---|---|
| KNOWN-1 | 删除的项目重启应用后，侧栏导航组仍短暂残留 | 再次打开/刷新项目列表后正常；重启侧栏状态文件可彻底清除 |
| KNOWN-2 | 远程 RWKV 隧道重启后 URL 会变化，旧地址显示离线 | 仅需更新 `appsettings.user.json` 中 `AI:Providers:RWKV:BaseUrl` 一处，无需重装/重编译 |
| KNOWN-3 | 「一键生成书籍」点击后立即开始（无确认弹窗） | 注意侧栏误触；生成过程可在进度弹窗观察 |
| KNOWN-4 | 批量生成运行中主程序文件被占用，无法覆盖升级 | 升级前先停止批量任务并退出应用 |

## 6. 安装与首次部署

1. **安装运行时**（如未安装）：下载并安装 [.NET 8.0 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/8.0)
2. **解压发行包**到任意本地目录（建议非系统盘，路径不含特殊字符）
3. **（可选）部署模型**：将 `.gguf` 模型文件放入 `rwkv_models\` 目录；如使用本地推理，启动 llama-server：
   ```
   llama-server --port 8000 --model rwkv_models\<模型文件>.gguf --ctx-size 65536 --parallel 4
   ```
4. **启动程序**：双击 `NovelManagement.WPF.exe`，按首次向导完成初始化
5. **配置 AI**（可选）：进入「AI 模型配置」页 → 选择默认提供者 → 填写服务地址或 API Key → 「测试连接」→「保存配置」

详细操作见《使用手册》（docs/使用手册_v1.0.0.md）。

## 7. 升级与数据迁移

- 数据库/配置/日志/备份全部位于 `%LocalAppData%\NovelManagement`，与程序目录分离——**覆盖升级程序目录不会丢失任何书籍数据**

- 旧版本 user 配置自动兼容，无需重配

## 8. 安全与隐私

- 全部书籍数据本地存储（SQLite），不上传任何服务器
- 诊断包导出时自动脱敏敏感配置项
- 用户自定义配置（含隧道地址、API Key）仅存于本机 `appsettings.user.json`，已列入 `.gitignore`，不随包分发
