## 1. 产品概览

书籍管理系统面向长篇小说/网文创作全流程，以本地 RWKV 大模型推理为核心 AI 引擎，提供「项目管理 → 设定构建 → 剧情规划 → 卷章写作 → AI 加工 → 质量体检 → 导出交付」的完整闭环。

### 功能全景

| 模块 | 能力 |
|---|---|
| 项目管理 | 多书并行、回收站、整包导入导出 |
| 内容管理 | 分卷/章节编辑、字数统计、章节命名 Agent |
| 设定体系 | 世界观、修炼体系、政治/商业/功法/装备等 20+ 维度 |
| AI 单点能力 | 润色（支持选中段）、续写、对话生成、设定分析、修为体系生成 |
| AI 流水线 | 对话式五级流水线、一键成书、长篇批量生成（断点续跑） |
| 质量保障 | 一致性检查、项目体检报告、统计报告 |
| 运维支撑 | 备份/恢复、诊断包、健康检查、日志 |

## 2. 安装与部署

### 2.1 系统要求

- Windows 10/11 x64
- .NET 8.0 Desktop Runtime（框架依赖发布，未安装请先到 https://dotnet.microsoft.com/download/dotnet/8.0 下载安装）
- 可选：RWKV 推理服务（本地 llama-server 或远程隧道）

### 2.2 安装步骤

1. 解压发行包到本地目录（建议路径不含中文/特殊字符，如 `D:\NovelManagement\`）
2. 双击 `NovelManagement.WPF.exe` 启动
3. 在「书籍管理系统 - 启动验证」窗口**输入启动密码**（由交付通知提供），点击「确定」
   - 密码错误会提示重输；点击「取消」退出应用
   - 密码验证在数据加载前完成，未通过不会触碰任何书籍数据
4. 按首次向导完成初始化（向导可随时在「发布管理 → 重新打开首次向导」再次唤起）

> 密码以 SHA-256 哈希比对，程序与文档中不存明文；请妥善保管交付通知中的密码。

**修改启动密码**：进入主界面后，打开侧栏「导入导出 → 发布管理」，在弹出的「发布与运维管理」窗口点击「**修改启动密码**」：

1. 输入当前启动密码
2. 输入新密码（不少于 6 位）并再次确认
3. 点击「确定」，提示「启动密码已更新，下次启动应用时生效」

自定义密码仅以哈希形式保存在用户数据目录的配置文件中，可随时重复上述步骤再次修改；删除该配置文件中的 `Security` 节点即可恢复出厂默认密码。

### 2.3 数据存放位置

所有用户数据独立于程序目录，存放在：

```
%LocalAppData%\NovelManagement\
├── data\        # SQLite 数据库（NovelManagement.db，核心数据）
├── config\      # appsettings.user.json（用户个性化配置）
├── logs\        # 运行日志（app-YYYYMMDD_NNN.txt）
└── backups\     # 数据库自动/手动备份
```

> 覆盖升级程序目录不影响上述数据；卸载仅需删除程序目录与上述数据目录。

### 2.4 （可选）部署 RWKV 推理服务

**本地部署**：将 `.gguf` 模型放入程序目录 `rwkv_models\` 下，启动 llama-server：

```
llama-server --port 8000 --model rwkv_models\<模型文件>.gguf --ctx-size 65536 --parallel 4
```

**远程隧道**：使用团队共享的远程 RWKV 服务时，其地址（形如 `https://xxxx.trycloudflare.com`）只需写入本机用户配置：

`%LocalAppData%\NovelManagement\config\appsettings.user.json`：

```json
{
  "AI": {
    "Providers": {
      "RWKV": {
        "BaseUrl": "https://<你的隧道地址>"
      }
    }
  }
}
```

> 隧道重启换 URL 后，只改这一处即可，无需重装或重编译。文件保存后重启应用生效。

## 3. 首次启动与界面基础

### 3.1 主界面布局

- **左侧栏**：固定入口（仪表盘、项目管理、AI 助手组、导入导出组）+ 当前项目的功能树（打开项目后自动展开）
- **顶部标题栏**：右侧机器人按钮开关「AI 创作助手」抽屉；主题切换按钮
- **中央工作区**：随导航切换的功能页面，窗口标题显示「小说管理系统 - <当前页面名>」可用于确认位置

### 3.2 侧栏导航

- 打开项目后，侧栏自动展开该项目分组
- 侧栏展开状态自动记忆：重启应用后恢复上次的展开/收起状态
- 图标按钮的悬停提示（ToolTip）即按钮功能名，如「打开项目」

### 3.3 主题与皮肤

- 支持白色/黑夜主题一键切换；黑夜模式下输入框、下拉框、弹窗均已深浅适配
- 「主题配置」页支持自定义皮肤；女频（言情类）书籍可自动应用 pink 皮肤

## 4. AI 模型配置（重点）

入口：侧栏「AI 模型配置」页。

### 4.1 配置顺序（推荐）

1. 选择默认提供者（RWKV / OpenAI / DeepSeek / Ollama）
2. 填写服务地址（RWKV）或 API Key（在线模型）
3. 点击「测试连接」，确认状态在线
4. 点击「保存配置」（写入 `appsettings.user.json`）

### 4.2 RWKV 服务状态

- 页面实时显示推理服务在线状态与已加载模型名
- 支持本地 llama.cpp 与远程隧道两种接入
- 润色/续写弹窗打开时会做两级在线探测（状态端点 3 秒 + 1-token 推理 6 秒）；离线或假死立即提示，避免长时间卡等

### 4.3 双 Agent 写作流

| Agent | 职责 |
|---|---|
| MainAgent | 正文创作（章节正文、润色、续写） |
| SubAgent | 需求整理与归档（设定分析、书名构思等） |

两个 Agent 可分别指定提供者与模型，适配「大模型写正文 + 小模型做整理」的组合。

### 4.4 连接故障排查

- **显示离线**：确认 llama-server 已启动、端口正确；远程隧道重启后 URL 已变——更新 `appsettings.user.json` 的 `AI:Providers:RWKV:BaseUrl`
- **润色弹窗模型下拉为空**：确认 `rwkv_models\` 目录下存在 `.gguf` 文件；服务在线时至少显示当前加载的模型
- **连接类英文报错**：v1.0.0 已统一转中文提示；若仍出现，按提示到「AI 模型配置」页检查服务

## 5. 核心创作工作流

推荐按以下顺序从零开始一本书（也可全程用 AI 创作助手对话式完成）：

```
第 1 步  仪表盘 →「＋ 新建项目」（书名、类型）
第 2 步  项目管理 →「打开项目」展开功能树
第 3 步  修炼体系 → 定义等级体系（手工或 AI 生成）
第 4 步  设定管理 → 世界观/势力/功法等设定（可 AI 分析）
第 5 步  剧情管理 → 总纲与主线/支线剧情线
第 6 步  卷宗管理 → 建分卷、建章节，进入编辑器写正文
第 7 步  正文加工 → AI 润色 / AI 续写 / 对话生成器
第 8 步  质量保障 → 一致性检查 / 项目体检报告
第 9 步  导入导出 → 整包导出 / TXT / DOCX
```

**快速路径**：直接使用「AI 创作助手」对话式流水线（见 7.2），由 AI 依次生成总纲→剧情线→分卷→章节草稿→章节正文，逐级确认采纳。

## 6. 功能页面详解

### 6.1 仪表盘

- **入口**：启动首页
- 快捷操作：「新建项目 / 导入项目 / AI 协作」
- 项目概览卡：总字数、章节数
- 最近活动时间线：真实动态（打开项目、生成进度等）
- 未打开项目时显示「未选择项目」

### 6.2 项目管理

- 工具栏：新建 / 导入 / 导出 / 项目列表 / 回收站 / 搜索
- 列表列：类型、状态、最近更新时间
- 行尾图标按钮：**打开项目**（展开侧栏功能树）、编辑项目、删除项目
- 删除为软删除，进入「回收站」可恢复或彻底删除

### 6.3 项目概览

- 打开项目后的默认页
- 左侧统计卡：完成度（如 6/10 章节、进度百分比）
- 中部：项目信息 + 最近剧情/设定回执
- 右侧：各管理页跳转入口

### 6.4 卷宗管理

- 新建分卷 → 卷内新建章节；章节支持排序与字数统计
- **双击章节**打开章节编辑器：标题/正文编辑，顶部提供「AI 润色」「AI 续写」按钮（详见 7.3/7.4）
- 章节命名 Agent 可主动生成主题化章节名

### 6.5 设定管理（含 20+ 子页）

- 侧栏「设定管理」分组包含：世界设定、修炼体系、政治体系、职业体系、司法体系、生民体系、灵宝体系、维度结构、地图结构、宠物体系、装备体系、功法体系、商业体系、时间线等子页
- 各子页操作一致：新建设定 → 填写详情 → 保存；左侧检索区按类型/分类过滤；支持 AI 分析与导入导出

### 6.6 剧情管理

- 管理主线/支线大纲、伏笔、时间线
- 支持标记重要级（重要级=10 视为总纲）
- AI 创作流水线的产物（总纲、剧情线）也落库于本页

### 6.7 角色管理

- 角色档案：姓名、身份、性别、年龄、外貌、性格、背景、修为等级、所属势力/种族
- **修为下拉框**自动加载本项目修炼体系中的自定义等级，并支持按体系自动回填
- **角色唯一性保障（v1.0.0 新增）**：
  - 创建/AI 生成角色时，系统自动检查同项目内是否已存在「同名 + 性格 + 背景」完全一致的角色；命中时**复用现有角色并提示**，不再产生无法区分的重复角色
  - **重名但描述不同**（性格或背景有区分）的角色可以正常创建
  - 如需创建同名角色，请在性格或背景描述上做出明确区分

### 6.8 关系网络

- 可视化角色关系图谱（师徒/敌对/亲属等）
- 支持缩放、拖拽、关系编辑；图幅自适应缩放

### 6.9 势力管理

- 门派/组织/家族档案：设定描述、层级结构、相互关系
- 角色所属势力在角色编辑中选择；势力分析由 AI SubAgent 支持

### 6.10 修炼体系

- 维护本书修炼等级：手工编辑，或点击 AI 生成自定义体系
- 等级顺序（Order）驱动角色修为回填与一致性检查
- 生成示例（八级）：灵根共鸣者 → 能量编织者 → … → 现实编织者 → 维度织者
- 注意：AI 生成前会检查是否已有体系，已有则跳过；需要重新生成请先删除旧体系

### 6.11 一键生成书籍

- 侧栏「AI 助手」组，**点击即开始（无确认弹窗），注意误触**
- 双 Agent 流程：构思书名 → 生成大纲 → 写第一章 → 自动创建新项目
- 适合快速获取创意样本

### 6.12 长篇批量生成

弹窗参数：

| 参数 | 说明 | 默认值 |
|---|---|---|
| 无限续写模式 | 不设卷数上限，持续写新卷直到手动取消 | 关 |
| 快速切卷 | 当前卷再写 3 章即切下一卷（验证跨卷衔接） | 关 |
| 每卷章节数 | 3–100 | 30 |
| 每章目标字数 | 800–10000 | 3000 |

- 任务后台运行，侧栏「生成进度」页实时查看当前卷/章与评分
- 中途关机/退出不丢进度：按章节切片落库，重启后断点自动续跑
- 参数修改只影响后续章节与新卷

### 6.13 AI 创作助手

详见 7.2。

### 6.14 AI 模型配置

详见第 4 章。

### 6.15 对话生成器

- 选择两个角色 + 给定场景 → RWKV 双 Agent 生成符合人设的对话
- 结果可一键插入章节或复制导出

### 6.16 一致性检查（项目体检报告）

- 四种检查：一致性检查 / 质量检查 / 全部检查 / 复检
- 结果三级着色（错误/警告/提示）按严重级别排序
- 每条问题附目标定位，可一键跳转对应页面
- 注意：窗口标题为「项目体检报告」

### 6.17 导入导出

- 项目整包导出（含书籍/卷章/人物/势力/设定/剧情）
- 从导出包导入恢复
- 内容导出：TXT / DOCX
- 建议导出前先「发布管理 → 立即备份数据库」

### 6.18 发布管理（运维中心）

一键操作：刷新健康检查 / 立即备份数据库 / 从备份恢复 / 导出诊断包 / 打开数据·日志·备份目录 / 重新打开首次向导

- 健康检查报告：总状态 + 逐项检查（数据目录、配置、数据库、日志、备份、运行环境）
- 诊断包：配置快照 + 日志摘要，敏感项自动脱敏，用于问题上报

### 6.19 统计报告

聚合当前项目：卷数、章节数、完成/草稿章节、角色/势力/剧情/设定数、总字数、平均每章/每卷字数。

## 7. AI 创作功能进阶

### 7.1 AI 润色（章节编辑器）

1. 双击章节打开编辑器，**选中一段文本**（不选 = 全文润色）
2. 点击「AI 润色」打开弹窗（此时自动做 RWKV 两级在线探测）
3. 模型下拉框自动列出 `rwkv_models\` 真实模型文件，服务当前加载的模型标「当前在线」并默认选中
4. 选择目标风格（如古典雅致）、润色强度（如中度）、特殊要求 →「开始润色」
5. 若有选中文本，先确认润色范围（所选段 / 全文）
6. 完成后查看「润色预览 / 替换项 / 智能建议 / 质量分析」→「应用润色」
   - 选中段模式：精准替换所选文本，其余不动
   - 全文模式：整章替换

### 7.2 AI 续写（章节编辑器）

1. 打开章节编辑器 →「AI 续写」
2. 设置面板配置续写参数（面板已修复为完整显示，可滚动）
3. 生成前自动执行 RWKV 在线检查；服务未启动会提示服务地址并指引到「AI 模型配置」页启动
4. 生成内容追加到正文尾部，可继续多轮无限续写

### 7.3 AI 创作助手（对话式流水线）

**打开**：标题栏机器人按钮，右侧滑出 380px 抽屉。

**能力一：意图导航**
- 输入「打开剧情管理」「去角色管理」等指令直接跳页
- 自然语言意图由规则优先解析，复杂语句由 RWKV 兜底；仅跳转白名单页面，绝不误导航

**能力二：五级创作流水线**

| 级别 | 产物 | 说明 |
|---|---|---|
| L1 | 总纲 | 全书故事纲要 |
| L2 | 剧情线 | 主线/支线 |
| L3 | 分卷 | 卷结构规划 |
| L4 | 章节草稿 | 逐章梗概（编号 1. 2. 3. …） |
| L5 | 章节正文 | 按草稿逐章成文（切片续写 + 防复读） |

- 每级产出以**确认卡**呈现：可单项采纳 / 修改（回复修改意见）/ 放弃，或整卡全部采纳 / 放弃重生成
- 同一时刻仅一张待处理卡，新卡自动将旧卡置为过期
- 进度持久化：重启应用后发送继续创作的消息即可接着做（流水线状态自动恢复）

**能力三：章节关联处理**
1. 点击输入框左侧**链接按钮** → 弹出 书→卷→章 三级级联选择 → 确认关联
2. 关联后抽屉顶部显示已关联横幅（可点「取消关联」解除）
3. 此后对话按内容自动分流：
   - 操作指令（如「把开头改得紧凑些」「按这个梗概写正文」）→ 直接对目标章节改写/成文，采纳后直接更新该章节
   - 疑问句（如「这章主角的动机是什么？」）→ 带章节上下文的问答
   - 含「取消关联」→ 解除关联
4. 关联处理与常规流水线相互独立，不会推进流水线状态

### 7.4 批量任务管理建议

- 批量生成期间主程序文件被占用，无法覆盖升级；升级前请停止任务并退出应用
- 长任务建议定期「发布管理 → 立即备份数据库」
- 断点续跑无需人工干预；如需放弃残留任务，可在生成进度页停止

## 8. 质量保障与统计

### 8.1 一致性检查 / 项目体检

- 入口：侧栏「一致性检查」组（「全部检查」= 一致性 + 质量全量跑）
- 检查维度举例：角色修为与体系等级匹配、设定冲突、剧情线引用完整性
- 问题条目可跳转修复；修完点「复检」验证

### 8.2 统计报告

- 「项目统计分析」弹窗查看聚合指标（卷/章/字数/实体数量）
- 可作为日更与产出节奏的参考基线

## 10. 常见问题 FAQ

**Q1：RWKV 显示离线？**
到「AI 模型配置」页检查服务地址与状态。本地先启动 llama-server；远程隧道重启后 URL 会变，只需更新 `appsettings.user.json` 的 `AI:Providers:RWKV:BaseUrl`。

**Q2：创建角色时提示「已复用现有角色」？**
这是 v1.0.0 的角色唯一性保护：同项目内已存在同名且性格、背景完全一致的角色。如确实需要两个同名角色，请在性格或背景描述上做出区分后再创建。

**Q3：AI 生成了很多重复角色怎么办？**
v1.0.0 已根治（服务层防重）并完成存量清理。若从旧版本升级后仍看到历史重复，属旧数据残留——可联系维护方执行一次清理脚本，或手工删除重复项。

**Q4：删除的项目去哪了？**
「项目管理 → 回收站」，可恢复或彻底删除。（已知问题：重启后侧栏可能残留该项目的导航组，属显示问题，不影响数据。）

**Q5：润色弹窗模型下拉为空？**
确认 `rwkv_models\` 目录存在 `.gguf` 模型文件；服务在线时至少显示当前加载的模型。

**Q6：批量生成中途关机会丢进度吗？**
不会。任务按章节切片落库，重启应用后从断点自动续跑；侧栏「生成进度」可查看当前卷/章与评分。

**Q7：一键生成书籍会弹确认吗？**
不会，点击侧栏按钮立即开始，请勿误触。

**Q8：数据存在哪里？如何备份？**
`%LocalAppData%\NovelManagement`（data/config/logs/backups）。「发布管理 → 立即备份数据库」一键完成。

**Q9：流水线做到一半关了应用，能继续吗？**
能。AI 创作助手进度已持久化，重新打开抽屉继续对话即可从当前级别接着生成。

**Q10：黑夜模式下弹窗/输入框样式异常？**
v1.0.0 已完成黑夜主题全覆盖修复；如仍遇到个别控件反色，请截图并上报日志时间点。

**Q11：启动密码输错或忘记密码怎么办？**
密码错误时窗口会提示重输，可多次尝试；取消则退出应用。密码由交付通知提供（程序与文档不存明文），忘记密码请联系交付方获取；每次启动都需要输入，应用不提供免输记忆。

**Q12：如何修改启动密码？自定义密码忘记怎么办？**
修改密码：进入主界面后在「发布管理」窗口点击「修改启动密码」，验证当前密码并设置新密码（≥6 位），下次启动生效。若自定义密码忘记：到用户数据目录的配置文件（`%LocalAppData%\NovelManagement\config\appsettings.user.json`）中删除 `Security` 节点，即可恢复出厂默认密码重新进入；也可联系维护方处理。
